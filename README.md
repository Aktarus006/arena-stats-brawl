# Arena Competitive Brawl Lab

Obsidian-friendly vault for tracking competitive Brawl decks, match reports, card performance, matchup notes, and deck changes on MTG Arena.

## Structure

- `Dashboard.md` — global overview across decks
- `Decks/<Deck>/` — deck-specific notes and results
- `Meta/` — recurring opposing commanders/archetypes and broader observations
- `Templates/` — reusable match-report templates

## Current tracked decks

- [[Decks/Squall/Overview|Squall, SeeD Mercenary]]

## Workflow

After each game, log the opponent, result, decisive cards, mistakes, mana issues, life-pressure issues, and any card that over- or under-performed. Deck changes are recorded separately so pre/post-change samples remain comparable.
