## Diagnosis

The current list contains only two true broad sweepers, so there will be games where a creature-heavy engine gets sufficiently wide/ahead that spot removal cannot efficiently recover.

Do not treat one game as proof that a third sweeper is required, but track future games where the explicit missing resource is a board wipe. If this repeats, the two-wipe configuration should be reconsidered.
