# Game 38 — Mighty Thor, Jane Foster

## Result
Loss in a close game.

## Opposing plan
The opponent played an artifact/equipment blink strategy. The main problem was the ability to repeatedly generate additional Equipment value, notably by **blinking Cloud, Midgar Mercenary** to tutor another Equipment each time.

**Mithril Coat** was among the Equipment that Squall struggled to answer profitably.

## Diagnosis
The game was competitive, but Squall could not sufficiently disrupt the opponent's accumulating artifact/equipment infrastructure. This is a different axis from the creature-heavy games where spot creature removal or sweepers are effective: once multiple Equipment remain in play, killing individual creatures may not remove the underlying value engine.

## Deckbuilding signal
Track this as an **artifact-pressure loss**. The current list does contain flexible answers such as **Cathar Commando**, but a single recursive/flexible artifact answer may be difficult to find against an engine that repeatedly tutors new Equipment.

Do not add dedicated artifact hate from one game alone. If similar losses recur, reassess whether the toolbox needs another broadly useful artifact/enchantment answer rather than a narrow hate card.
